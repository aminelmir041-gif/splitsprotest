SPLITSPRO - GITHUB PAGES STATIC VERSION

Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
You should see these directly in the repo root:
  index.html
  site.css
  logo.png
  robots.txt
  sitemap.xml
  static/

GitHub settings:
  Settings -> Pages
  Source: Deploy from a branch
  Branch: main
  Folder: /(root)

No .github folder, npm, package.json, or build action is required for this version.
