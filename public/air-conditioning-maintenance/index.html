Air Conditioning Maintenance for Sydney Homes

Find the indoor model number and its operating manual first. A wall split can have a washable mesh filter and a separate fine filter with different care instructions. A ducted system usually has its main filter at the return-air grille.

A simple routine for the start of the season

  1. Check the filter instructions. Follow the manufacturer’s shutdown and access instructions. Clean only owner-accessible filters using the method in the manual. Some fine filters need replacing. If a washable filter is rinsed, let it dry as directed before refitting it.
  2. Look along the air path. Move curtains and furniture clear of the indoor inlet, outlet and return grille. From a safe position, check that the outdoor unit has clear airflow around it. Leave covers and electrical compartments closed.
  3. Try the rooms you actually use. Note the mode, set temperature, fan speed and which zones are open. Check whether the problem affects one bedroom, every room or only the afternoon period. That detail helps the technician narrow down the cause.

Use your manual’s interval as the starting point. Daily use, pets and renovation dust can mean the filter needs attention sooner. Daikin’s filter care guidance is a reference for Daikin owners.

Does it need a clean, a service or a repair?

Persistent odour or visible build-up inside a wall split
A clean mesh filter can sit in front of a dirty coil or fan wheel. See what our split system deep clean covers.
Weak airflow across a ducted home
Check the accessible return filter and controller settings first. If airflow remains weak, a service visit can assess the fan, zones and air path.
Repeated shutdowns, a fault code or water leaking indoors
Stop using the affected unit and arrange fault diagnosis. Photograph the code or leak location if you can do so safely. A cleaning booking alone may miss the cause.

What to send with a booking

Include the suburb, model number, a photo of the controller and a short description such as “airflow is weak in both rear bedrooms with the doors closed”. Mention when you last checked the filter and whether heating and cooling behave differently.
